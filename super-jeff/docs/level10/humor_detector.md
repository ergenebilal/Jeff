# humor_detector.py

**Ne işe yarar?** Espri, ironi, alay, abartı, kelime oyunu ve kuru mizah türlerini tespit eder. Uygun duygusal tepkiyi üretir.

**Nasıl çalıştırılır?**
```
python3 ~/.hermes/scripts/humor_detector.py detect "Tabii ki yine her şey harika"
python3 ~/.hermes/scripts/humor_detector.py test
```

**Örnek çıktı:**
```

   Yanıt: İroni dozajın yüksek bugün 😄
```
