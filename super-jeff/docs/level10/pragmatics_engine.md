# pragmatics_engine.py

**Ne işe yarar?** Bir cümledeki söylenmeyen anlamı, alt metni çıkarır. Yardım isteme, sitem, onay bekleme, memnuniyetsizlik, hafife alma gibi imaları doğru yorumlar.

**Nasıl çalıştırılır?**
```
python3 ~/.hermes/scripts/pragmatics_engine.py analyze "Şef, bu iş biraz karışık"
python3 ~/.hermes/scripts/pragmatics_engine.py test
```

**Örnek çıktı:**
```

🔍 ALT METİN: yardım_isteme
```
