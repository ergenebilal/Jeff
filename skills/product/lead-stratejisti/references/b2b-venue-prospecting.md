# B2B Mekan Prospecting — Sanat/Dekor Sektörü İçin

> **Kullanım senaryosu:** El işi/dekor/heykel/sanat üreticilerine (Tuğba gibi) müşteri bulmak için mekan tarama stratejisi.

## Felsefe

Normal lead stratejisti "dijital hizmet" satar. Bu strateji "fiziksel dekor/sanat" satar.
- Kanal: soğuk e-posta değil, kişisel görüşme (portföy göster)
- Lead: web araması değil, Instagram/Görsel analiz
- Skor: web varlığı değil, mekanın konsept/yenilik durumu

## Sinyal Tarama Kriterleri (Hotspot Skorlaması)

| Sinyal | Soru | Puan |
|--------|------|------|
| Yeni açılmış | Son 3 ayda mı açıldı? | +20 |
| Yenilenmiş | "Yenilendik" postu var mı? | +20 |
| Konseptli | Teması var mı? (endüstriyel, bohem, minimal) | +20 |
| Boş duvar | Fotolarda duvarlar boş görünüyor mu? | +20 |
| Instagram estetiği | Fotojenik olmaya özeniyor mu? | +15 |
| Rakip sanat kullanmış | Benzer mekanlar duvar sanatı yaptırmış mı? | +10 |
| Fiyat seviyesi | Ortalama üstü mü? (bütçesi var) | +10 |

- **70+ puan = 🔥 SICAK:** Git konuş
- **50-70 = 🟡 ILIK:** İzle, 1 ay sonra tekrar kontrol et
- **<50 = ⚪ SOĞUK:** Şimdilik boşa kürek

## Haftalık Teslimat Formatı

Her Pazartesi 10-15 fırsat şu formatta:

```
🔥 [Mekan Adı] — [Lokasyon]
   → Neden: [sinyal açıklaması, örn: "2 hafta önce açılmış, duvarlar boş, konseptli"]
   → IG/Web: [link]
   → Not: [varsa referans/ortak tanıdık bilgisi]
```

## Uygulama Adımları

1. **Portföy hazırla** — Sanatçı/dekor üreticisi elindeki işlerin görsellerini toplar
2. **Sistem tara** — Instagram/Google Maps'ten mekanları tara, hotspot skorla
3. **Fırsatları sun** — Her Pazartesi listede ulaştır
4. **Sanatçı konuşur** — İlgilendiği mekana portföyünü gösterir, işi bağlar

## Araçlar

- Instagram Business Discovery API (eğer FB token varsa)
- Google Maps/Places API (yeni açılan mekanlar için)
- Web/mekan Instagram scraping (görsel analiz için)
