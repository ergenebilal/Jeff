# Önce Mimari — Architecture First Development Pipeline

Bu metodoloji GSD çekirdeğini tamamlar. Her geliştirme ihtiyaçtan production'a 9 adımda ilerler.

## Pipeline
İhtiyaç → Business Case → SPEC → SOP → İmplementasyon → Test → Monitoring → Production → Review

## System Architecture Upgrade Protocol
Büyük sistem evrimlerinde uygulanır:
1. Vizyon analizi + mevcut durum karşılaştırması
2. Gap analizi + phased roadmap
3. Her bileşen: SPEC → SOP → Kod → Test
4. Cron/otomasyon bağla
5. Raporla
6. Skill + memory güncelle
