# AI Agency Client Onboarding Checklist

## Phase 1: Discovery Call (Day 1)

- [ ] Client's business model and revenue drivers understood
- [ ] Current manual processes documented
- [ ] Pain points ranked by cost/impact
- [ ] Existing tech stack inventoried (CRM, email, calendar, etc.)
- [ ] Budget range established
- [ ] Decision-maker identified and engaged
- [ ] Competitor automation level assessed
- [ ] Timeline expectations set
- [ ] Deliverable 1: Discovery Summary Document

## Phase 2: Scope Definition (Day 2-3)

- [ ] Process maps created for top 3 automation candidates
- [ ] Automation complexity scored (Simple/Medium/Complex)
- [ ] ROI projection per automation (hours saved × hourly cost)
- [ ] Integration requirements listed (API access needed)
- [ ] Data migration needs assessed
- [ ] Security/compliance requirements documented
- [ ] Success metrics defined (KPIs)
- [ ] Deliverable 2: Project Scope Document with ROI

## Phase 3: Contract & Legal (Day 3-4)

- [ ] Service agreement signed
- [ ] NDA signed (if applicable)
- [ ] Payment terms agreed (50% upfront / 50% on delivery)
- [ ] Data processing agreement (GDPR/KVKK compliance)
- [ ] SLA defined (response time, uptime, support hours)
- [ ] IP ownership clause confirmed
- [ ] Deliverable 3: Signed Agreement Packet

## Phase 4: Setup & Access (Day 4-5)

- [ ] Client's API keys collected (list below)
- [ ] Sandbox/test environment provisioned
- [ ] Client granted read-only access to dashboard
- [ ] Communication channel established (Slack/Telegram channel)
- [ ] Regular check-in schedule set (daily during build, weekly after)
- [ ] Emergency contact protocol defined
- [ ] Billing/usage tracking configured
- [ ] Deliverable 4: Access & Environment Setup

## Phase 5: Development (Day 6-14)

- [ ] Workflow 1: build → test → client review
- [ ] Workflow 2: build → test → client review
- [ ] Workflow 3: build → test → client review
- [ ] Error handling and alerting configured
- [ ] Monitoring dashboard set up
- [ ] Documentation written (for client's team)
- [ ] Deliverable 5: Working Workflows + Documentation

## Phase 6: Deployment (Day 15-16)

- [ ] Production environment ready
- [ ] Data backed up before migration
- [ ] Workflows deployed to production
- [ ] Client team trained (30-min walkthrough session)
- [ ] Test run with real data (10+ transactions)
- [ ] Rollback plan documented
- [ ] Go-live checklist signed off
- [ ] Deliverable 6: Go-Live Confirmation

## Phase 7: Post-Launch (Week 3-4)

- [ ] 24-hour post-launch check-in
- [ ] Week 1: performance review against KPIs
- [ ] Week 2: optimization based on real usage data
- [ ] Bug fixes and edge case handling
- [ ] Client testimonial requested
- [ ] Case study drafted (for your portfolio)
- [ ] Referral request (warm introductions)
- [ ] Monthly retainer or support plan offered
- [ ] Deliverable 7: Performance Report + Case Study

---

## Required API Keys & Access Checklist

- [ ] OpenAI API key (or equivalent LLM provider)
- [ ] Telegram Bot Token (if using Telegram)
- [ ] Google Cloud / Sheets API access
- [ ] Slack API token (if using Slack)
- [ ] Social media API access (if relevant)
- [ ] Database read-only credentials
- [ ] CRM API access (HubSpot, Salesforce, etc.)
- [ ] Email service access (SendGrid, Gmail API, etc.)
