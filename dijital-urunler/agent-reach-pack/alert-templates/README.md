# Alert Template: Brand Mention

**Trigger:** Your brand name mentioned on social media or forums

```
🚨 Brand Mention Detected

Source: [Platform]
Mention: "[Direct quote]"
URL: [Link to mention]
Author: [Username]
Sentiment: [Positive/Neutral/Negative]
Engagement: [Likes/Retweets/Replies]

Suggested action:
- 🟢 Positive: Engage and thank
- 🟡 Neutral: Monitor for follow-up
- 🔴 Negative: Escalate to support team
```

**Response time target:** < 30 minutes for negative sentiment
